# 04 現代美術のアーティスト

## 1. いちばんの問題
液体が器の手前で別の素材にすり替わる。HYDRAは黒く重い艶なのに、器で上がるのは波形に切った写真で、重さがない。HYDRAは減らず、器は線1pxの閉じた四角で口がない。本人のものはHYDRAだけ、枠と時計は借り物。

## 2. 決めるべきこと
- 器に入る液をHYDRAと同じ黒い艶にし、満杯の0.6秒後に澄んで作品が出る
- 量を保存する。1器満ちるたびHYDRAを縮め、7器で直径6割
- 器を作品の縦横比のままの3辺にする(上は開け、底は3px)
- 等速0.9秒をやめ、速く入り遅く上がる1.4秒にし、縁で2px盛り上げて止める
- 「SWIPE TO CUT」を「掬う」にし、手を動かした方向の器から満たす

## 3. 削るもの
右上の時刻表示。液とも器とも無関係な流行の引用。

## 4. 仕掛け
案件1つ=ひと掬い。詳細ページで、それを画像の数だけの器(Sho-Timeなら7つ)へ順に注ぎ、最後の器で尽きる。固まると器の線が外れ、作品だけが残る(脱型)。同じ液が瓶にも袋にも花瓶にもなる、本人の仕事の形。

## 5. スマホ
- 一掬いの後は、縦に送る量=注ぐ量。器が下端から中央へ来る間に満ちる
- 器を画面の外へ切らない(幅は画面−40px)。液面は送る速さで最大8°傾き、止めると2回揺れる

## 6. 譲れない点
「すぐ見せろ」と対立する。Topで液が満ちて澄む約2秒は削らない。Works一覧は満ちた状態で始めてよい。
