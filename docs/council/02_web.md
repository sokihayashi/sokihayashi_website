# 02 ウェブデザイナー

## 1. いちばんの問題
満ちた器が入口でない。外側の器84個は無題で押せず、Wixの無記名142枚と同じ。位置も絞り込みもURLに残らず、詳細から戻ると切る前の空の器に戻る。

## 2. 決めるべきこと 5つ
- 器は1器=1案件(約40)にし、題名付きで詳細へ飛ばす。
- Topは代表8件だけ。絞り込みは/worksのみ、`?d=branding&s=client`で持つ。0件のタグは押せなくする。
- ヒーローの名前と肩書きを20px以上に(いま約11px)。無操作3秒で自動で注ぐ。
- 現在地は「03 / 08」に案件名を添え、`#w=3`に書く。戻れば満ちたまま同じ器へ。
- 詳細は、表紙1枚→案件名・領域・立場・年→画像3〜7枚→次の案件1件→Contact。文なしで成立させる。

## 3. 削るもの
ヘッダーの時計。液体にも導線にも無関係。

## 4. この考えだから成立する仕掛け
ページ遷移を「注ぎ替え」にする。押した器から液が引き、同じ液が詳細の表紙を満たす。液面は画像の読み込み量に連動し、読み込み表示を兼ねる。

## 5. スマホで変えること 2つ
- 作品の間隔を画面1枚分にし、指を離すと1作品で止める。いまは62°で3枚見え、題名が切れる。
- タグと主要リンクを下端の親指圏へ。1行、高さ44px。

## 6. 他の専門に譲れない点
「切るまで作品を見せない」には反対。戻る・共有・再訪では演出を飛ばし、満ちた状態で同じ位置を出す。
